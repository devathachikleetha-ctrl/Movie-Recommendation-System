\# Movie Recommendation System



\## Objective



The Movie Recommendation System recommends movies similar to a user's selected movie using Machine Learning.



\## Dataset



MovieLens dataset containing 9742 movies.



\## Technologies Used



\- Python

\- Pandas

\- Scikit-learn

\- TF-IDF

\- Streamlit



\## Machine Learning Method



Content-Based Filtering is used to recommend movies based on genre similarity.



TF-IDF converts movie genres into numerical features, and similarity is calculated to find similar movies.



\## Features



\- Select a movie

\- Get Top 5 movie recommendations

\- Display similarity scores

\- Display movie posters

\- Interactive Streamlit interface
